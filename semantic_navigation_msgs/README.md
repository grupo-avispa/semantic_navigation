# semantic_navigation_msgs

## Overview
This package provides actions to interact with the [semantic_navigation](../semantic_navigation) package.

## Services (.srv)
* [SemanticGoals](srv/SemanticGoals.srv): Generate random goals in regions determined by names.
* [SemanticPosition](srv/SemanticPosition.srv): Get the name of a region given a position.
* [SemanticRegions](srv/SemanticRegions.srv): Get the names of the regions.
