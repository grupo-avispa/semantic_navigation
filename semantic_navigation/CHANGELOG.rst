3.4.0 (02-08-2026)
------------------
* Align the metapackage version with ``semantic_navigation_msgs``, ``semantic_navigation_tasks``, ``semantic_navigation_bt`` and ``semantic_navigation_rviz_plugins``, which are now released in lockstep.
